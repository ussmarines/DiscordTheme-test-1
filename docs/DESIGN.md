# Parhelion

Cold light, measured depth.

Parhelion separates navigation, conversation and supporting information into calm planes. Its narrow blue selection line and restrained menu translucency give orientation without competing with messages.

## Geometry

12px corners, inset navigation, framed chat plane, translucent menus only when hardware acceleration is available.

## Typography and motion

Discord's own font stack and user font size remain intact. Hierarchy comes from grouping, spacing and weight; code alone uses the native monospace. Native icons remain identifiable and user roles retain their colors. Background changes last 140ms; no theme animation loops. Reduced motion disables authored transitions.

## Decisions

No photographs, external fonts or icon libraries. An original geometric logo is documentation-only. No decorative dashboard labels, invented telemetry or cosmetic controls. Glass is restricted to small menus and disabled when hardware acceleration is off.
